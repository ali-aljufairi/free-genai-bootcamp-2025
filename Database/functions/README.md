# Database Functions

This directory contains PostgreSQL functions for the Sorami language learning platform.

## Files

- `user_tracking_functions.sql` - User progress tracking and analytics functions
- `hiragana_to_romaji.sql` - Japanese text conversion functions
- `srs.sql` - Spaced repetition system functions

## Function Categories

### User Tracking
Functions for tracking user progress, study sessions, and performance analytics.

### Text Processing
Functions for converting Japanese text formats (Hiragana ↔ Romaji).

### Learning Algorithms
Spaced repetition algorithm implementation for optimal learning scheduling.

## Usage

These functions are automatically loaded by the import process and used by the application backend for various operations.
